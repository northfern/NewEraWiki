# Партия РОСТА

**Партия РОСТА** - радикально-правая Эррландская и Берлинская партия. Находилась у власти с 17.05.22 по 25.06.22.

Являлась прямой противницей Коммунистической Партии Эррландии. У власти отстаивала интересы Берлина и БАО.
