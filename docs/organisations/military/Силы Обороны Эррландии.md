# Силы Обороны Эррландии
**Силы Обороны Эррландии (Errlandika Defensio Virium)** - нерегулярные и полуавтономные воинские подразделения, подконтрольные Верховному Совету ЭНСР.

Были созданы как отряды быстрого реагирования для защиты границ ЭНСР во время Войны за Независимость. Комплектуются преимущественно из добровольцев и иностранных экспедиционных корпусов.
