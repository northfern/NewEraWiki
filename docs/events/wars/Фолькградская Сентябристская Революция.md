# Фолькградская Сентябристская Революция
**Фолькградская Сентябристкая Революция** - революционное событие, произошедшее в ФГ во время Астрало-Эррландской войны. Положило конец проэристскому и проастральскому сопротивлению на востоке ЭНСР.

## **Фолькградская Сентябристская революция**

### **Дата**: 07.12.24-09.12.24

### **Противники**: 
Силы Оброны Эррландии, РКА СФГ, Эррландская Народная Советская Республика, Фолькградская Республика _против_ Силы Сопротивления Фолькграда, сторонники нейтралитета, Фолькградская Астральская Республика.

### **Командующие**:  
- ЭНСР: daynikene, pral11  
- Фолькградская Астральская Республика: APOIOP, drank\_god

### **Итог**:  
- Восстановление конституционного строя ЭНСР на территории ФГ  
- Депортация сторонников ФАР из ФГ
