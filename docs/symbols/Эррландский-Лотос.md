# Эррландский Лотос

**Эррландский Лотос** - старейший национальный символ Эррландских государств. Зачастую, его окрас на флаге выражает политические убеждения государства.

* * *

![green lotus](green%20lotus.png){ .center-img loading=lazy }

Лотос Новой-Эррландии. Использовался центристами и лево-либералами, а также пре-эристами.
{:.center}

![lotus](lotus.png){ .center-img loading=lazy }

Лотос ЭНСР-ЭССР. Используется сентябристами и коммунистами. На данный момент является одним из символом борьбы за Эррландскую государственность.
{:.center}
  

![purple lotus](purple%20lotus.png){ .center-img loading=lazy }

Лотос Эриского Союза. Использовался эристами во время Черного Марта и Лихой весны.
{:.center}


![dark purple lotus](dark%20purple%20lotus.png){ .center-img loading=lazy }

Лотос СФГ Эррландии. Использовался эррландскими коммунистами на 4-м Сезоне НЕ.
{:.center}

  

* * *

Эррландский Лотос - основной символ, обозначающий принадлежность государства к Эррландским. Вместе с республиканскими цветами флага, он образует основные государственные символы Эррландии.

* * *

![kos](kos.png){ .center-img loading=lazy }

Эррландский лотос, перекрывающий Республиканскую Звезду, на эмблеме КОС IV Эррландской Республики
{:.center}

## История создания

Первая версия Эррландского Лотоса была создана Фелисом 20.12.2021

![first lotus](first%20lotus.png){ .center-img loading=lazy }

Он должен был символизировать красоту, доброту, естественность, возрождение (после исхода из PaperVanilla) и вечное процветание Эррландского народа.

Эта версия не была представлена общественности, ведь была создана игроком, а не администратором.

22.12.2021 была представлена уже традиционная версия Лотоса, созданная Авиор по той же концепции.
